# COOLEX website

A responsive Arabic and English website for COOLEX. It uses plain HTML, CSS, and JavaScript; no build is needed.

## Preview

Run `python3 -m http.server 8080` in this directory, then open `http://localhost:8080`.

## Contact details

The published design initially displays **example details** that cannot send messages. Set the verified email address and international WhatsApp number in `CONTACT_SETTINGS` at the top of `script.js` to activate the links. Keep the phone number as digits, including country code, with no plus sign.

The product descriptions reflect the photographed package; confirm them against the final product before public launch.

## GitHub Pages

Publish this directory to the public `HornetGeek/coolex` repository. In repository Settings → Pages, choose **Deploy from a branch**, the default branch, and **/(root)**. The expected address is `https://hornetgeek.github.io/coolex/`. Relative asset URLs and `.nojekyll` support project Pages hosting. Verify the deployed address before sharing it.
